# Nhạc nền (Music)

Bỏ **bản nhạc dài** (1–3 phút trở lên, tốt nhất làm sẵn để lặp liền mạch) vào đây:

- `Menu/`     — nhạc chủ đề MainMenu (1 bản có giai điệu nhận diện là đủ; 1 bản thì tự lặp liền mạch).
- `Gameplay/` — 3–4 bản cùng phong cách (Adventure / Strategy / City Life / Competition). Phát xáo trộn, không lặp liền kề.

Sau khi thêm file: chạy menu **Tools ▸ CoTyPhu ▸ Build All Screens** để gán vào Scene.
Chưa có file ⇒ Scene không có nhạc nền (chỉ còn hiệu ứng).
Chỉ dùng nhạc tự tạo/CC0/đã được cấp phép; giữ file giấy phép cạnh bản nhạc (như Kenney/OFL của dự án).
